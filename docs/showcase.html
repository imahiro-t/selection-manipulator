入出力例の表記
  • ⏎ = 改行
  • ⇥ = タブ
  • · = 意味のある空白
  • {U+XXXX} = 不可視文字（コードポイント）
  • [a] = 選択範囲
  • | = カーソル位置
  • （通知） = 結果を通知で表示する
  • 入力の後ろの（ ）は、コマンド実行時に入力する値やカーソル数などの補足です。
  • 文字列リテラルの \n などは「バックスラッシュ + n」の 2 文字を表します（実際の改行は ⏎）。
  • WS-015（空白の可視化）の出力側と WS-016（可視化を戻す）の入力側では、· と → は表記記号ではなく実際の文字です。
